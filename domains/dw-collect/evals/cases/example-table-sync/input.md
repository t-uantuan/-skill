# example-table-sync · 输入（模板）

> 落地时按真实历史单重构一份自己的 golden case（复制本目录改名），填入真实大白话与四要素。
> golden case 的作用：冻结一个"已知答案"的历史任务，供改 skill 前后跑回归。

## 大白话原文

> 〈把〈表X〉也加进每天的数据采集里，别每天全量搬，就同步有变化的，补历史的时候别出岔子，跑完对一下数。〉

## 四要素（补全）

- 谁用：〈每日调度链路/下游分析角色〉
- 决策：〈表X〉进增量还是全量
- 时限：〈绝对日期〉
- 样例：〈一个可读的历史实施记录引用〉

## 背景事实（真实）

- 〈表X〉是 lastmodified 型增量表，检查列含〈检查列A〉/〈检查列B〉（〈检查列B〉可为 NULL，真实风险源）
- 历史实测：〈日期〉同分区重跑使该表行数非预期增长（幂等事故，见 failure-modes FM-A03）
