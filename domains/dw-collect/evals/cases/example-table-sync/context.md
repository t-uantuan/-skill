## 源表事实（冻结）

- 表：`〈业务库〉.〈表X〉`（〈数据库类型与版本〉）
- 集群：〈集群A〉（〈节点1-3〉，〈用户名〉）；数据库在〈节点1〉
- 同步方式：〈批量导出工具〉增量（lastmodified 型），脚本 `〈增量同步脚本〉`
- 检查列：`〈检查列A〉`（选定）；`〈检查列B〉` 可为 NULL，是真实风险源，不用于增量判断
- 断点：`〈业务库〉.〈断点控制表〉.断点值`（注意保留字风险）；写入后必须回读
- 幂等机制：临时目录 + 原子 mv（同分区重跑行数不变）
- 密码文件：`〈密码文件路径〉`（字节数与换行状态须断言）
- 落盘路径：`〈落盘根路径〉/〈表X〉_inc/<dt>/`；ODS：`〈ODS库〉.〈表X〉_inc`（dt 分区）
- 对账：`〈对账脚本〉`（源库 vs 落盘行数）；append 表 0 行属正常不算异常

## 术语引用

术语口径以 `specs/glossary.yaml`（采集链路术语节）为准，本 case 用到：增量同步 / 首日全量初始化（--init）/ 断点控制表 / 幂等 / 对账。术语表更新时同步核对本文件。

## 历史事故锚点

〈日期〉同分区重跑行数非预期增长（幂等事故，体系编号 FM-A03）——本 case 的断言 AS-2 直接打在它上面。
