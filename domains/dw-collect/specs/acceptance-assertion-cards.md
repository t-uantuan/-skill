# 验收断言形态卡（模板）

> 定位：执行方可见的断言形态定义（评分答案的"形态"部分从答案件外移至此；具体裁决值仍走升级包）。
> 来源：golden case 拍板表＋expected 断言＋双跑分叉教训。
> 维护规则：新验收场景追加新卡或新行；查不到的形态走升级包，不编（与 glossary 同规）。
> 落地时把〈表X〉〈断点控制表〉〈对账脚本〉等替换为本域实际对象。

| 断言 | 形态定义 | 禁止形态 |
|---|---|---|
| AS-1 对账 | 源库全表 count = 落盘全部累计 count = ODS 全表 count，三方直比 diff=0；并调〈对账脚本〉输出 diff=0 | 只比两方；只比行数不比内容；以"脚本 OK 自述"替代输出比对 |
| AS-2 幂等 | 同一分区：重跑前 count 与重跑后 count 直比相等；分区须有非零数据（空分区不构成证据） | 用"脚本声明支持幂等"替代实测；只在空分区验证 |
| AS-3 断点 | 〈断点控制表〉断点值非空（写入后回读）；次日断点值 ≥ 前值（单调不减）；检查列口径按裁决值取 MAX 对照 | 只查"行存在"不查值；用日志自述替代回读 |
| AS-4 ODS 臂 | **当日分区直比**：`〈ODS库〉.〈表X〉_inc WHERE dt=<当日>` count ↔ 落盘**同分区**文件行数 wc -l | **以全历史/全分区累计替代当日分区直比**；条件化（"如果做了 X 才查"） |
| 查询限时 | ODS 验收查询限时 30s（人审拍板值；历史事故口径仅作记录不再使用） | 只写"及时返回"无限时值 |
| 凭据 | 各工具原生文件机制（数据库客户端→defaults 文件、批量导出工具→password 文件） | 命令行展开密码；环境变量中转（工具无文件机制时除外并注明）；混用他工具旗标 |
