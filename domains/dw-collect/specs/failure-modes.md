# 失败模式清单（体系种子）

来源：真实事故与历史问题清单，全部发生过、全部有证据（证据细节存运行目录，不入本清单）。
检查方式三档：**机**=脚本可判 / **语**=独立复核判 / **人**=升级包拍板。
每条标注：由哪个 skill/gate 负责杀。

## 使用规则

1. meta-requirement 产出的每条验收标准，必须标注它杀的是本清单哪一条（FM-xx）。
2. 每次踩坑归因后，新失败模式**先加进本清单**，再回写 skill。
3. 太具体的教训（如"某库某列名要反引号"）进 skill 的 checks，不进本清单——本清单保持模式级通用。
4. **唯一属主**：每条的"杀它的位置"必须唯一且与 skill 实装一致；检查未实装的（暂缓链路）必须写明"启用时实装"，不许指一个没有该检查的位置。
