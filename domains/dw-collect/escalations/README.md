# escalations · 升级包样例（脱敏）

本目录放升级包**格式样例**，不是真实单的升级包——实际单的升级包落 `runs\<id>\escalations\`。

| 文件 | 类型 | 计入预算 |
|---|---|---|
| `E-YYYYMMDD-NN.md` | 任务级升级包（含：口径/方案/豁免/确认包） | 计入，每单 ≤3 个 |
| `EP-YYYYMMDD-NN.md` | 流程级升级包（改标准/改骨架/流程缺陷） | 不计入 |

格式定义见 `skeleton/skills/meta-requirement/SKILL.md`「升级包格式」节（字段：问题 / 冲突缺口依据 / 杀 / 阻塞 / 选项 ≤3 / 推荐+依据 / 本单预算）。
两份样例可直接复制改名使用；样例编号 `20260101` 仅为格式示意，落地时按实际日期与序号替换。
