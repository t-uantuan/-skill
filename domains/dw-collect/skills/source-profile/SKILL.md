# 源表探查

## 步骤

1. `SHOW CREATE TABLE` → 存表结构；列名过数据库保留字清单（杀 FM-A08 前置）。
2. 找检查列：增量表必须有单调递增列；查该列 NULL 率（可空时间列是真实事故源，见 failure-modes）。
3. 行数基线：源表 count 存档（对账的分母）。
4. 密码文件：`wc -c` 断言字节数与预期一致、无尾部换行（杀 FM-A04）。
5. 环境探测：进程清单 / 端口（依赖服务如缓存 6379 等，杀 FM-A15）。

## 输出格式

profile.md 逐项给"命令 + 实际输出 + 判定"，不给转述。
